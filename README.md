# RonoTrade Dashboard Demo
A mobile-friendly static prototype containing a CEO/admin dashboard and user dashboard.

Important: this is a UI/demo only. It does not process real deposits, withdrawals, KYC, brokerage orders, or real-money binary options.

## Publish from Android
1. Create a GitHub account at https://github.com/
2. Create a new repository, e.g. `ronotrade-dashboard`.
3. Upload `index.html`, `style.css`, `app.js`, and `README.md`.
4. For an easy public link, import the repository into Vercel at https://vercel.com/
5. Deploy. Your site will receive a `vercel.app` address.

For production, replace the demo logic with a secure backend, database, authentication, KYC, audit logging, and properly licensed payment/trading infrastructure.
